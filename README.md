# City Events MVP

Prosty portal do agregacji i przeglądania wydarzeń w mieście.

## Cel MVP
1. Zbieranie wydarzeń z 1-2 źródeł RSS/HTML.
2. Zapisywanie ich w prostej bazie danych (SQLite).
3. Udostępnienie prostego API.
4. Wyświetlenie listy wydarzeń na prostej stronie.
